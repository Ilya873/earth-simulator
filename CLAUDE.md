# CLAUDE.md — сайт Earth Simulator

Лендинг игры Earth Simulator: звёздная карта развития (дорожная карта), летопись версий и полевой дневник (девлог).
Jekyll на GitHub Pages (классическая сборка из ветки `main`: Jekyll 3.10, Liquid 4, kramdown GFM, плагин jekyll-feed).
Сборки и зависимостей нет — коммит в `main` публикует сайт. Репозиторий: `Ilya873/earth-simulator`,
адрес: https://ilya873.github.io/earth-simulator/ (`baseurl: /earth-simulator` — все ссылки через `relative_url`;
в `body_en` записей, который Liquid не обрабатывает, пути пишутся с `/earth-simulator/…`).

## Публикация записи дневника

- Файл: `_posts/YYYY-MM-DD-latin-slug.md`. Шапка: `title`, `summary` (обязательно); `title_en`, `summary_en`,
  `version`, `cover`, `cover_caption`, `cover_caption_en`, `body_en: |` (английский текст в Markdown) — по желанию.
  `lang` по умолчанию `ru` (задано в `_config.yml`).
- Медиа — в `assets/devlog/YYYY-MM-DD-slug/`. Скриншоты ужимать до 1600 px по ширине (и копия 800 px), JPEG q≈82,
  progressive (Pillow есть в системе). Обложка 16:9 — она же превью ссылки в Telegram.
- Вставки: `{% include figure.html src=… caption=… wide=true %}`, `{% include gallery.html images="a|b" captions="…|…" %}`,
  `{% include video.html youtube|rutube|vk|src=… caption=… %}`. Свои ролики — до ~20 МБ, длинные — на хостинг видео.
- Текст разработчика публиковать как есть (без переписывания); голос — от первого лица, без смайлов.
- Не публиковать содержимое невыпущенных обновлений, пока разработчик явно не попросил.

## Дорожная карта (звёздная карта)

- Данные — `_data/roadmap.yml`: `phases` — обновления (звёздные системы), `items` — планеты на орбите;
  тексты `ru`/`en`, пункт = `[заголовок, пояснение]`. Статусы: `done | wip | plan | idea`.
  `now: true` — «Вы здесь», ровно у одного обновления. `req: true` — идея игроков (фильтр на карте).
  `deps` — зависимости (линии на карте и ссылки «Опирается на / Открывает путь»).
  `t` — дата в долях года (шкала времени), `pos` — координаты на карте 1400×640 (x растёт со временем; держать x монотонным по t).
- `grows` — «Что станет глубже в уже существующем»: как обновление развивает уже готовые механики (работа, лавки, закон,
  поручения, базы…). Механики не делаются один раз: 2.1 даёт основу, 3.0 переводит их на «правила как данные»
  (условия на факты о мире), каждое следующее обновление добавляет факты и правила, не переписывая механику.
- Связи `deps` должны совпадать с текстом «Почему в этом месте» (если в тексте сказано «нужно X из 3.4» — 3.4 есть в deps).
- Подписи на звёздной карте раскладываются автоматически (starmap.js → placeLabels), координаты `pos` можно двигать свободно.
- Отдельной главы «просьб игроков» нет — идеи вписываются пунктами в подходящие обновления с `req: true`.
- Сроки всегда ориентировочные («≈»), без обещаний точности.
- Обновление выпущено → `status: done`, пункты → `s: done`, `now: true` переносится на следующее;
  в `_data/versions.yml` добавить версию сверху; в «Паспорте мира» (`pp_version_v` в i18n.yml) обновить версию.

## Летопись версий и Telegram

- `_data/versions.yml` — версии по новостям Steam (`steam` — id новости, `tg` — номер поста, `post` — запись дневника).
- `_data/telegram.yml` — номера постов канала gamesforfarmnews про игру; на сайте виджетом показывается только самый новый (первый в списке).
  Если Telegram не даёт встроить пост (виджет пишет «Please open Telegram to view this post», как у закреплённого №3916),
  пост описывается карточкой: `id`, `date`, `title`, `text` (ru/en), `img` — она ведёт на пост в Telegram.
- Виджет Steam встроен iframe-ом (`store.steampowered.com/widget/4932460/`), масштабируется скриптом.

## Оформление

Концепция — «Атлас Земли и звёзд»: ночное тёмно-синее поле, пергамент текста, латунь (`--brass`) только как акцент
(номера разделов, главная кнопка, наведение), бирюза (`--verd`) — «в работе» и идеи игроков.
Титул — физическая карта (canvas), дорожная карта — звёздная (SVG + canvas). Фоны разделов — размытые кадры игры
(`assets/img/bg/*.jpg`, затемнены и с переходом в фон, сделаны Pillow).
Правила, о которых просил разработчик:
- мало мелкого текста: служебных подписей минимум, текст не мельче ~15 px;
- никаких точек/кружков-маркеров перед пунктами списков;
- никаких двойных рамок, обводок у кнопок, карточек и картинок; линий — минимум (тонкие, пергамент 13 %);
- на звёздной карте по умолчанию только линия маршрута, зависимости — при наведении, без стрелок;
- не использовать кремово-терракотовую гамму (похожа на сайт Claude), «таблетки», градиенты, неон, стекло, эмодзи.
Шрифты: Alegreya / Alegreya SC (заголовки), Alegreya Sans SC (кнопки), IBM Plex Mono (только координаты на карте).
Все цвета — переменные в начале `assets/css/main.css`.
