## Когда нужен код

Всё, что описано в главах про [редактор]({{ '/modding/editor/' | relative_url }}) и [mod.json]({{ '/modding/data/' | relative_url }}), — **данные**: игра читает их и сама решает, что с ними делать. Данными можно сделать сценарий, мир, баланс, эпохи, биомы, модели. Но новую *механику* данными не описать: «первые сто лет войн не бывает», «столица у моря добавляет стабильности», «своё окно со своей таблицей», «на прогулке клавиша O надевает кольчугу». Для этого у дополнения есть **код** — обычный JavaScript, который игра подключает рядом со своими файлами.

Код может:

- **читать весь мир** — клетки карты, державы, города, войны, хронику, людей;
- **менять мир** внутри его шага — население, казну, стабильность, климат, загрязнение;
- **подписываться на события** — новый год, рождение и гибель держав, войны, бедствия, прогулка;
- **оборачивать функции игры** — менять их результат или вовсе отменять вызов;
- **добавлять интерфейс** — окна, кнопки, слои карты, вкладки страницы державы, табло и клавиши прогулки, записи хроники;
- **править файлы игры по якорю**, когда до нужного места иначе не добраться.

Готовые примеры всего этого — в главе [«Что можно менять кодом»]({{ '/modding/recipes/' | relative_url }}): десять небольших дополнений, каждое проверено в игре.

## Как игра подключает код

Код дополнения игра подключает **сама при каждом запуске**, в памяти: файлы игры на диске не меняются, установщики не нужны. Steam обновляет игру как обычно, а дополнение продолжает работать.

Для игрока дополнение с кодом выглядит как любое другое: **одна галочка** в «Мастерской» включает его целиком — и данные, и код. Отличий два:

1. После подписки дополнение с кодом **выключено**, пока игрок сам не поставит галочку. Код выполняется с правами игры, и подписка сама по себе не должна запускать чужую программу. Найдя такое дополнение, игра подсказывает, что его можно включить.
2. Код подключается **при запуске игры**, поэтому включённое дополнение заработает после перезапуска: под списком появляется кнопка «Перезапустить» (мир уходит в автосохранение, как при выходе).

{% include figure.html src="/assets/modding/ws-ru-1600.jpg" caption="«Мастерская» с десятью дополнениями из примеров: у каждого — галочка, у подключившихся — никаких лишних надписей." wide=true %}

Под названием дополнения строка появляется, только когда есть что сказать:

| Строка | Что значит |
|---|---|
| «Заработает после перезапуска» | галочку только что поставили |
| «Выключится после перезапуска» | галочку сняли, а код ещё работает |
| «Несовместимо с этой версией игры» | правка по якорю не нашла своё место, нет нужного файла игры и т. п. |
| «Ошибка в дополнении» | синтаксическая ошибка в скрипте — исправить может только автор |
| «Файлы дополнения повреждены» | нет файла из раздела `code` или он вне папки дополнения |
| «Нужна более новая версия игры» | `minGame` новее установленной игры |
| «Выключено: игра не запустилась с этим дополнением» | сработала страховка (ниже) |

Подробная причина — для автора — во всплывающей подсказке у этой строки: например, «в файле people.js не нашлось место правки». «Несовместимо» и «Ошибка в дополнении» игра видит заранее, ещё до галочки: она разбирает код, не запуская его.

**Страховка.** Если запуск игры с кодом дополнений не дошёл до конца (ошибка или зависание при загрузке), при следующем запуске эти дополнения выключаются сами, а игрок видит уведомление. Сломанное дополнение не может «запереть» игру. Исправьте ошибку и поставьте галочку снова.
{: .note}

## Первое дополнение за десять минут {#first}

Сделаем дополнение, которое раз в 50 лет пишет в хронику, сколько людей живёт в мире, а при запуске мира показывает приветствие.

**1. Папка.** Откройте папку игры (в библиотеке Steam: правый щелчок по игре → «Управление» → «Просмотреть локальные файлы») и в папке `mods` создайте папку `hello-world`:

```
Earth Simulator/
  mods/
    hello-world/
      mod.json
      hello.js
```

**2. `mod.json`** — описание дополнения и раздел `code` со списком скриптов:

```json
{
  "id": "hello-world",
  "name": { "ru": "Привет, мир", "en": "Hello, world" },
  "author": "Ваше имя",
  "description": { "ru": "Моё первое дополнение с кодом.", "en": "My first code add-on." },
  "version": "1.0",
  "code": {
    "minGame": "2.2.0",
    "scripts": ["hello.js"]
  }
}
```

**3. `hello.js`** — сам код:

```js
// hello.js — первое дополнение с кодом
(function () {
  'use strict';

  // мир создан и игра запущена — показываем приветствие
  ModAPI.started(function () {
    UI.toast({ title: T('Привет, мир', 'Hello, world'), text: T('Дополнение работает', 'The add-on works'), icon: 'globe' });
  });

  // каждый новый год; y — номер года
  ModAPI.on('year', function (y) {
    if (y % 50 !== 0) return;
    let pop = 0;
    for (const st of states) if (st.alive) pop += st.pop;
    logEvent('people', TF('Год {0}: в мире живёт {1} человек', 'Year {0}: {1} people live in the world', y, UI.fmt(Math.round(pop))));
  });
})();
```

Файлы — в кодировке UTF-8 (Блокнот, VS Code, Notepad++ так и сохраняют).

**4. Включите.** Запустите игру → «Мастерская» → галочка у «Привет, мир» → «Перезапустить». После перезапуска — новая игра: появится приветствие, а каждые 50 лет в хронике — строка о населении.

**5. Правьте и перезапускайте.** Галочку ставят один раз; дальше игра перечитывает файлы дополнения при каждом запуске. Поменяли скрипт — нажмите «Перезапустить игру» в «Мастерской».

Почему всё обёрнуто в `(function () { … })();`: скрипт работает в **общей области видимости** с игрой. Объявленные на верхнем уровне `const` и `let` попадают в неё, и два дополнения с одинаковым именем ломают друг друга. Наружу выставляйте только то, что действительно нужно, — с приставкой своего дополнения в имени.
{: .note}

## Раздел `code` в `mod.json` {#code-section}

```json
"code": {
  "minGame": "2.2.0",
  "scripts": [
    "main.js",
    { "file": "js/walk-extra.js", "after": "walk.js" },
    { "file": "js/early.js", "before": "civ.js" }
  ],
  "patches": [
    { "file": "people.js", "find": "  function _pDie(p, cause, year) {",
      "insertAfter": "\n    if (typeof deathsHook === 'function') deathsHook(p, cause, year);" }
  ]
}
```

| Поле | Что значит |
|---|---|
| `minGame` | необязательно: с какой версии игры работает код; на более старой игрок увидит «Нужна более новая версия игры» |
| `scripts` | свои скрипты по порядку |
| `patches` | правки файлов игры по якорю (см. [ниже](#patches)) |

**Скрипты.** Просто имя файла — скрипт исполняется **после всех файлов игры**, когда мир ещё не создан. Так подходит почти всегда. `{ "file": …, "after": "walk.js" }` или `{ "file": …, "before": "civ.js" }` ставит скрипт сразу после или перед указанным файлом игры — если коду нужно успеть раньше остальной игры.

- Путь — внутри папки дополнения, можно с подпапкой.
- Место — имя файла игры (`civ.js`, `walk.js`, `ui.js`…). Раньше `keys.js` встать нельзя.
- Если в одно место встают скрипты нескольких дополнений, порядок между ними не задан.
- Каждый скрипт заранее проверяется на синтаксис. Ошибка — код дополнения не подключается, а в «Мастерской» написано, в каком файле и строке.
- Если скрипт бросит исключение при исполнении, следующие скрипты этого дополнения не запускаются; игра работает дальше.

У дополнения может быть только раздел `code` — или код вместе со сценариями, мирами, балансом. Данные такого дополнения работают, только пока работает его код.

## Что видно коду {#globals}

Скрипт видит все глобальные имена игры. Главные из них:

### Клетки карты — `W` и `GRID`

Карта — сетка клеток `GRID.W × GRID.H` (`GRID.N` клеток всего). Номер клетки `i = y * GRID.W + x`; помощники `idx(x, y)`, `inB(x, y)`, широта строки `latOf(y)`. Всё, что лежит в клетке, — типизированные массивы в объекте `W`, по одному значению на клетку:

| Массив | Что в нём |
|---|---|
| `W.elev`, `W.isWater`, `W.isCoast`, `W.slope` | высота (0…1, уровень моря — `W.seaLevel`), вода, побережье, крутизна; `landH(i)` — высота над морем 0…1 (1 = 5000 м) |
| `W.temp`, `W.tempSmoothed`, `W.precip` | температура °C (сейчас и без сезонов), осадки мм в год |
| `W.biome`, `W.veg`, `W.fertility`, `W.eco` | биом, растительность, плодородие, здоровье природы |
| `W.pop`, `W.urban`, `W.stateId` | население клетки, городское население, номер державы (−1 — ничья) |
| `W.culture`, `W.religion`, `W.res` | культура, вера, месторождение |
| `W.pollution`, `W.industry`, `W.fire`, `W.ruin`, `W.fallout` | загрязнение, промышленность, пожар, разрушения, радиация |
| `W.herb`, `W.pred`, `W.fish` | звери: травоядные, хищники, рыба (0…1) |
| `W.distOcean`, `W.landmass` | расстояние до моря в клетках, номер материка или острова |

И общие значения мира: `W.simYear` (год, дробный), `W.co2`, `W.solar`, `W.seaLevel`, `W.pace` (темп истории), `W.paused`.

### Державы — `states`

`states` — массив держав. Мёртвые остаются в нём с `alive: false`, и их место (`id`) потом занимает новая держава. Поэтому **держава надолго запоминается по `uid`** — сквозному номеру, который не повторяется: `stateByUid(uid)` вернёт живую державу или `null`.

| Поле | Что в нём |
|---|---|
| `id`, `uid`, `alive`, `name`, `color` | место в массиве, сквозной номер, жива ли, имя, цвет `[r, g, b]` |
| `capital`, `cells`, `area` | клетка столицы, `Set` клеток, сколько их |
| `pop`, `tech`, `era`, `gov`, `ideo` | население, наука, эпоха (`eraName(era)`), строй, идеология |
| `stability`, `treasury`, `gdp`, `military` | стабильность 0…1, казна, ВВП, армия |
| `atWar`, `relations`, `overlord`, `bloc` | воюет ли, отношения (`Map` id → число), сюзерен, блок |
| `culture`, `religion`, `piety`, `ruler`, `dynasty` | культура, вера, набожность, правитель и династия |
| `born`, `cityCount`, `largestCity` | год основания, сколько городов, самый большой город |

### Остальное

- **Войны:** `wars` (идущие), `warLog` (все); `warBetween(a, b)`, `powerOf(st)` — военная сила.
- **Хроника:** `worldEvents` (новые — первыми), `logEvent(вид, текст, данные)` — новая запись.
- **Города:** `cityName(i)`, `cityInfo(i)`; названия мест — `placeNameAt(i)`.
- **Люди:** `personById(id)`, `rulerOf(st)`, `personName(p)`.
- **Числа баланса:** таблицы `CIV`, `CLIM`, `ECO`, `FAU`, `DIS`, `WALK`… — те же, что правит раздел `balance`.
- **Интерфейс:** `UI.win`, `UI.table`, `UI.toast`, `UI.icon`, `UI.esc`, `UI.fmt`; `focusCell(i)` — показать клетку на карте; `openStateDetail(st, вкладка)` — страница державы.

Имена, которые начинаются с `_`, — внутренние: они могут меняться от версии к версии, не опирайтесь на них. Всё остальное игра обещает не убирать (см. [Совместимость](#compat)).
{: .note}

### Тексты и языки

Игра на 17 языках. Любой текст для игрока пишите через `T('по-русски', 'in English')`, с подстановками — `TF('Год {0}', 'Year {0}', y)`. На остальных языках игрок увидит английский вариант. Не склеивайте фразу из кусков (`T('Держава ') + name`): в другом языке слова стоят иначе — берите шаблон с `{0}`.

Имена из мира (держав, городов, людей) попадают в разметку **только через `UI.esc()`**: игрок может назвать державу как угодно.

## ModAPI {#modapi}

`ModAPI` — стабильная часть игры для авторов: она не меняется от обновления к обновлению. Всё, что можно сделать через неё, делайте через неё.

| Вызов | Что делает |
|---|---|
| `ModAPI.on(событие, fn)` | подписка на событие мира |
| `ModAPI.walkOn(событие, fn)` | подписка на событие прогулки |
| `ModAPI.wrap(имя, fn, id)` | обёртка над функцией игры: `fn(orig, ...аргументы)` |
| `ModAPI.before(имя, fn, id)` | `fn(...аргументы)` перед функцией игры; вернула `false` — функция игры не вызывается |
| `ModAPI.after(имя, fn, id)` | `fn(результат, ...аргументы)` после; вернула не `undefined` — это новый результат |
| `ModAPI.ready(fn)` | все файлы игры загружены, мира ещё нет |
| `ModAPI.started(fn)` | мир создан, игра запущена |
| `ModAPI.version` | версия игры, например `"2.2.0"` |
| `ModAPI.report()` | дополнения с кодом и их состояние |

### Что когда исполняется

1. Скрипты с местом (`after`, `before`) — в своём месте порядка загрузки.
2. Скрипты без места — сразу после последнего файла игры.
3. `ModAPI.ready` — все файлы игры загружены; мира ещё нет.
4. Создание или загрузка мира — события `worldgen` или `load`.
5. `ModAPI.started` — мир создан, игра запущена.

Новая игра из меню, загрузка и запуск сценария перезапускают страницу, и скрипты исполняются заново. Но мир может смениться и без перезапуска (новый мир кнопкой, «Сброс жизни»), поэтому своё состояние сбрасывайте по событиям `worldgen` и `reset`, а из сохранения читайте по `load`.

## События мира {#events}

`ModAPI.on(имя, fn)` — `fn` получает аргументы из таблицы. Ошибка в подписчике пишется в консоль один раз и не останавливает мир.

| Событие | Аргументы | Когда |
|---|---|---|
| `worldgen` | `type` | мир создан заново |
| `reset` | — | «Сброс жизни»: люди стёрты, рельеф и климат остались |
| `year` | `y` | наступил новый год |
| `civTick` | — | закончился шаг цивилизаций (≈ 15 дней) |
| `stateNew` | `st, parent, how` | родилась держава; `how`: `tribe`, `player`, `secede`, `revolt`, `colony` |
| `stateDead` | `st, cause, by` | держава исчезла; `cause`: `conquered`, `collapse`, `depop`, `merged` |
| `eraChange` | `st, from, to` | держава перешла в другую эпоху |
| `govChange` | `st, from, to, how` | сменился строй; `how`: `reform`, `revolution`, `coup`, `silent` |
| `war`, `peace` | `w` | война началась / закончилась (объект войны) |
| `event` | `e` | запись попала в хронику: `{ year, type, text, d }` |
| `save`, `load` | `o` | мир сохраняется / загружен (см. [ниже](#save)) |
| `contact` | `a, b, how, cell` | две державы впервые встретились |
| `seaDiscovery` | `st, cell, first` | первая колония на другой земле |
| `stateCollapse` | `st, lost` | империя потеряла провинции |
| `rules` | `key, value, prev` | изменилось правило мира |
| `ideoChange` | `st, from, to, how` | сменилась идеология |
| `warCell` | `w, cell, side, defUid` | клетка перешла из рук в руки на войне |
| `civilWar` | `w, st, rebels` | гражданская война |
| `treaty` | `tr, w` | заключён договор |
| `blocNew`, `blocEnd` | `b` / `b, why` | блок создан / распался |
| `councilNew` | `council` | создан Мировой совет |
| `rightsChange` | `st, kind, from, to` | изменились права меньшинств |
| `worldWar` | `w` | война стала мировой |
| `rivalry` | `a, b` | две державы стали соперницами |
| `nuketest` | `st, cell, kt` | ядерное испытание |
| `disasterPre`, `disaster` | `type, cell, power, byPlayer` / `d, type, cell, byPlayer` | бедствие сейчас ударит / уже ударило |
| `godPower` | `name, cell, r, s` | применена благая сила |
| `ruin` | `cell, how, why` | клетка стала руинами или перестала ими быть |
| `landmark` | `L, what` | достопримечательность заложена, построена, повреждена… |
| `company` | `c, what, …` | компания основана, закрыта, национализирована… |
| `ancStart`, `ancCiv`, `ancWave` | `n` / `st, key, wave` / `wave, made, skipped` | исторический старт: начался / появилась древняя держава / волна новых народов |
| `faunaSpecies` | `sp` | добавлен вид животных (из дополнения) |

**Не меняйте мир из обработчика `event`.** Хроника отбрасывает повторную запись по тексту, а текст — на языке игрока: в сетевой игре одна и та же запись может попасть в хронику на одном компьютере и не попасть на другом. Подписывайтесь на само событие (`war`, `ruin`, `disaster`…). Читать мир и что-то показывать из `event` можно.
{: .note .warn}

## Обёртки над функциями игры {#wrap}

Обёртка встаёт вместо функции игры и решает, звать ли оригинал и что вернуть. Три формы:

```js
// before: вернули false — функция игры не вызывается
ModAPI.before('disasterTrigger', function (type, cell, power, byPlayer) {
  if (type === 'meteor' && !byPlayer) return false;   // метеориты — только по воле игрока
}, 'my-mod');

// after: вернули не undefined — это новый результат
ModAPI.after('powerOf', function (power, st) {
  return st.gov === 'theocracy' ? power * 1.25 : power;   // теократии на четверть сильнее
}, 'my-mod');

// wrap: полный контроль; orig — функция игры (или обёртка другого дополнения)
ModAPI.wrap('declareWar', function (orig, att, def, cause, force) {
  if (!force && W.simYear < 100) return null;   // первые сто лет ИИ не воюет
  return orig(att, def, cause, force);
}, 'my-mod');
```

Правила:

- Обернуть можно только **глобальную функцию, объявленную через `function`** на верхнем уровне файла игры. Имена через `const` и `let` и функции внутри замыканий (например, почти весь `people.js`) так не достать — для них [правки по якорю](#patches).
- Оборачивайте, когда функция уже есть: в скрипте без места или в `ModAPI.ready`. Нет функции — вызов вернёт `false` и напишет об этом в консоль.
- Несколько дополнений могут обернуть одну функцию: обёртки встают цепочкой.
- **Упавшая обёртка отключается**: ошибка пишется в консоль, функция игры работает без неё. Третий аргумент — id вашего дополнения: по нему видно, чья обёртка упала.
- `orig()` без аргументов передаёт исходные аргументы, `orig(a, b)` — ваши.
- Когда `before` отменяет вызов, функция возвращает `undefined`. Если вызывающему нужен определённый ответ (например, `null` — «не вышло»), берите `wrap`.
- Обёртка добавляет работы каждому вызову: не оборачивайте функции, которые зовутся тысячи раз за шаг.
- **Не оборачивайте `climateStep`, `ecologyStep`, `civTick`, `computeCurrents` и `simEmit`.** С 2.2 шаг мира на больших картах делится на части, чтобы кадры шли ровно; обёртка над этими функциями выключает деление, и большие карты начинают подёргиваться. Подпишитесь на событие (`civTick`, `year`) или сделайте правку по якорю внутри функции.

Если игра заранее сохранила ссылку на функцию (подписала её на событие, положила в таблицу), этот вызов пройдёт мимо обёртки.
{: .note}

## Свои данные в сохранении {#save}

```js
let level = 0;
ModAPI.on('save', function (o) { o.ext['my-mod'] = { level: level }; });
ModAPI.on('load', function (o) {
  const d = o.ext && o.ext['my-mod'];   // раздела нет — старое сохранение или без дополнения
  level = d ? d.level : 0;
});
ModAPI.on('worldgen', function () { level = 0; });
```

- Ключ в `o.ext` — id вашего дополнения; остальные ключи принадлежат игре.
- Кладите только то, что переживает JSON: числа, строки, массивы, простые объекты. `Map`, `Set` и типизированные массивы переведите в массивы.
- Раздела может не быть — начните с чистого листа.
- В сетевой игре сохранение — это и есть снимок мира для нового игрока: всё, что вы кладёте в `save`, получит каждый, кто войдёт в комнату.

## События прогулки {#walk}

`ModAPI.walkOn(имя, fn)` — прогулка от первого лица.

| Событие | Аргументы | Когда |
|---|---|---|
| `init` | — | сцена прогулки готова, игрока ещё нет |
| `enter` | `cell, opts` | игрок вошёл в прогулку |
| `arrive` | `cell, how` | игрок появился на клетке: `enter`, `teleport`, `respawn` |
| `cell` | `cell, prev` | игрок перешёл на другую клетку мира |
| `exit` | `cell` | игрок уходит с прогулки |
| `dispose` | — | сцена разбирается: уберите свои объекты |
| `clear` | `all` | всё живое вокруг убирается |
| `update` | `dt` | каждый кадр; `dt` — секунды |
| `sync` | — | раз в секунду |
| `hud` | — | обновляются табло (`wkHudSet`) |
| `kill` | `victim, by` | повержен житель, зверь или машина; `by === 'player'` — игроком |
| `fire` | `key, weapon` | игрок ударил или выстрелил |
| `loot` | `npc, out` | обыск тела: допишите своё в `out.msgs`, `out.ammo`, `out.wpn` |
| `cast` | `pl, add, rng, cast` | клетка заселяется: `add(kind, x, z, yaw, o)` добавляет своего жителя |
| `vehWreck` | `v, by` | транспорт разбит |
| `blast` | `x, y, z, R, dmg, by` | взрыв |

Эти события ждут ответа (ничего не вернуть — игра поступит как обычно):

| Событие | Аргументы | Что вернуть |
|---|---|---|
| `crime` | `level, x, z, victim, info` | `true` — розыск вы берёте на себя |
| `hurt` | `dmg, why` | число — новый урон игроку (броня) |
| `death` | `why` | `true` — что дальше, решаете вы |
| `canTeleport` | — | `false` или строка-причина — переноситься нельзя |
| `battle` | `b, cell, d` | `true` — бой рядом разыгрываете вы |
| `junction` | `v, cell, legs` | один из `legs` — куда ехать машине |

Табло прогулки: `wkHudSet('имя', html)` (пустая строка прячет), сообщение внизу экрана — `wkMsg(текст, 'good')`. Клавиши — таблица `WK_KEYS` (имя клавиши → `fn(e, k)`, вернуть `true` — клавиша взята); не затирайте чужой обработчик, а встаньте в цепочку, как в [примере]({{ '/modding/recipes/' | relative_url }}#walk).

## Правки по якорю {#patches}

Когда до места не добраться ни событием, ни обёрткой (код внутри замыкания, середина длинной функции), правка ищет в файле игры **якорь** — кусок кода, который встречается в этом файле ровно один раз, — и меняет текст рядом с ним.

| Поле | Что делает |
|---|---|
| `file` | файл игры: `people.js`, `civ.js`… |
| `find` | якорь — точный кусок текста из этого файла |
| `replace` | заменить якорь этим текстом |
| `insertBefore` / `insertAfter` | вставить текст перед якорем / после него |
| `insertBeforeFile` / `insertAfterFile` | вставить содержимое файла из папки дополнения |

Пример: весь `people.js` (правители, династии) спрятан в замыкание. Правка вставляет в начало `_pDie` — смерти любого человека — одну строку, которая зовёт функцию дополнения:

```json
"patches": [{
  "file": "people.js",
  "find": "  function _pDie(p, cause, year) {",
  "insertAfter": "\n    if (typeof deathsHook === 'function') deathsHook(p, cause, year);"
}]
```

`typeof` в правке — страховка: если скрипт дополнения не исполнился, игра работает так, будто правки нет. Целиком этот пример — в [рецептах]({{ '/modding/recipes/' | relative_url }}#patch).

Правила:

- **Якорь встречается в файле ровно один раз.** Не нашёлся или нашёлся дважды — код дополнения не подключается.
- **Всё или ничего.** Если хоть одна правка не встала, откатываются все правки дополнения, его скрипты не запускаются, а в «Мастерской» написано почему.
- Изменённый файл заранее разбирается; если он перестал разбираться — дополнение не подключается.
- Текст вставляется как есть: переводы строк ставьте сами (`\n`). Концы строк CRLF или LF значения не имеют.
- Нельзя править `three.min.js`, `i18n.js`, `demomode.js` и `modboot.js` — они загружаются раньше правок.

**Как выбрать якорь.** Сначала попробуйте ModAPI — он не зависит от текста кода. Если без правки никак: одна характерная строка (объявление функции, особый комментарий), без чисел баланса и текстов для игрока. **Правка — мостик, логика — в скрипте**: вставляйте одну строку, которая зовёт вашу функцию. Единственность проверьте поиском по файлу игры в папке игры.
{: .note}

Если строка якоря лишь сдвинулась по отступу или перенеслась, игра всё равно её найдёт: она ищет якорь и без учёта пробелов и переносов, если такой кусок в файле один.

## Сетевая игра {#net}

В комнате каждый игрок считает всю симуляцию сам, а по сети идут только команды. Поэтому у всех в комнате должны быть одни и те же дополнения — игра сравнивает их содержимое и с другим набором в комнату не пустит. Чтобы миры не разошлись:

- События мира (`ModAPI.on`) и обёртки функций симуляции выполняются **внутри шага** на каждом компьютере. `Math.random` там выдаёт всем одинаковые числа — пользуйтесь им как обычно.
- **Не меняйте мир из таймера, кнопки или клавиши**: это случится только на одном компьютере. Зарегистрируйте действие через `netAct` и вызывайте `netDo` — в комнате оно выполнится у всех в один момент, вне комнаты это обычный вызов:

```js
netAct('mymod_quake', function (cell) {
  // аргументы приходят из сети — проверяйте их
  if (Number.isInteger(cell) && cell >= 0 && cell < GRID.N) disasterTrigger('quake', cell, 1, true);
});
// в обработчике кнопки:
netDo('mymod_quake', cell);
```

- Данные, сохранённые через `save`/`load`, доходят до новичка вместе с миром. Данные, которые живут только в переменной, — нет: новичок начнёт без них, и миры разойдутся.
- Действия на прогулке, меняющие мир (подобрать, наградить), регистрируются через `netFree(имя, fn, check)` и вызываются `netDoFree(имя, …)`. Ведущий сначала зовёт `check(from, args)`: `1` — принять, `0` — отказать, `-1` — подождать. Без `check` действие не принимается.
- Звуки, всплывающие сообщения и окна — это интерфейс, а не мир: их можно показывать где угодно. `netRemote()` — правда, пока выполняется чужая команда (например, чтобы не играть звук за другого игрока).

Если миры всё же разойдутся, игра заново пришлёт гостю мир ведущего и покажет уведомление с названиями включённых дополнений с кодом. Проверить дополнение просто: две копии игры в комнате локальной сети, несколько минут игры.
{: .note}

## Скорость

Игра должна идти и на встроенной графике, поэтому:

- Не проходите по всем клеткам **каждый кадр**. Раз в год или раз в шаг цивилизаций (`year`, `civTick`) — можно: это дёшево даже на карте 1000×1000.
- Окна перерисовывайте по событиям мира или не чаще раза в секунду.
- Не создавайте объекты в горячих местах (событие `update` прогулки, обёртки частых функций).
- Табло **F3** покажет время кадра и шага мира — сравните с дополнением и без.

## Отладка {#debug}

- Почему дополнение не подключилось — в строке под его названием в «Мастерской», подробно — во всплывающей подсказке у этой строки.
- Сообщения консоли (`console.log`, ошибки ваших скриптов, предупреждения ModAPI) видны, если запустить игру из командной строки с ключом `--enable-logging=stderr`:

```
EarthSimulator.exe --enable-logging=stderr 2> log.txt
```

  В журнале скрипт дополнения называется `mods/…/имя.js`, исправленный правкой файл игры — `people.js?modpatched`.
- Пока пишете, проще всего выводить отладку прямо в игру: `UI.toast({ text: '…' })` или запись в хронику.
- Уронили запуск — следующий запуск пройдёт без вашего кода, а дополнение выключится: исправьте ошибку и поставьте галочку снова.
- Встроенный редактор сохраняет раздел `code` как есть, но пока его не показывает: файлы скриптов он перечислит среди тех, «на которые дополнение не ссылается», — удалять их не нужно.
- Напишите в описании дополнения, что в нём есть код и что он делает: игрок решает, доверять ли вам. Код не должен трогать на компьютере ничего, кроме игры.

## Совместимость с обновлениями {#compat}

Цель — чтобы дополнение не приходилось переделывать под каждую версию игры.

- **Имена игры не пропадают.** Всё, что объявлено на верхнем уровне файлов игры и не начинается с `_`, поля таблиц (`UI.win`, `CIV.ERA_TECH`…), события и `ModAPI` начиная с 2.1.3 не исчезают: если обновлению нужно что-то переименовать, старое имя остаётся рядом и ведёт на новое.
- **Проверка перед каждой сборкой игры.** Сборка сама сверяет открытые имена со всеми выпущенными версиями и проверяет все дополнения с кодом, которые когда-либо видела. Если обновление сломало бы то, что работало, сборка останавливается.
- **Якорь переживает правки рядом.** Если обновлению нужно изменить саму строку якоря известного дополнения, в игру добавляется псевдоним «старый якорь → новый».

Поэтому всё, что можно сделать через `ModAPI`, события и открытые имена, делайте через них. Правки по якорю — запасной путь. Если правка всё-таки перестала вставать, игроки увидят «Несовместимо с этой версией игры», а игра будет работать без дополнения.

## Старые пакеты с кодом

Дополнения, сделанные до 2.1.3 под установщики, подключаются без переделки: игра узнаёт `patches.json` с правками по якорям и пакеты со своей копией `index.html`. Правки **по номерам строк** перенести на другую версию игры нельзя — номер строки сдвигается от любой правки выше по файлу; игрок увидит «Несовместимо», а автору нужно перейти на раздел `code` с якорями. Если игрок когда-то запускал старый установщик, пусть проверит целостность файлов игры в Steam («Свойства» → «Установленные файлы» → «Проверить целостность»).
