* Оглавление
{:toc}

Почти всё, что описано на этой странице, можно собрать мышкой во встроенном [редакторе дополнений]({{ '/modding/editor/' | relative_url }}). Эта глава — для тех, кому удобнее править текст: редкие параметры, массовые правки, работа во внешнем редакторе. И для тех, кто хочет точно знать, что игра делает с их файлом.

Редактор пишет ровно тот же `mod.json`, что описан здесь. Можно сочетать оба способа: начать в редакторе, а потом поправить файл руками — и наоборот.
{: .note}

## Как устроено дополнение

### Где лежат дополнения

Дополнение — это папка с файлом `mod.json`. Свои дополнения лежат в папке `mods` рядом с игрой. Найти папку игры проще всего через Steam: правой кнопкой по игре в библиотеке → **Управление → Просмотреть локальные файлы**. В игре туда же ведёт кнопка **«Папка модов»** в разделе **Мастерская**.

```
Earth Simulator/
  mods/
    example-pack/    готовый образец, загляните в него
    my-pack/         ваше дополнение
```

Подписки Мастерской Steam лежат в папках Steam — их игра находит сама, класть их в `mods` не нужно.

### Самый короткий путь

1. Скопируйте папку `example-pack` рядом и переименуйте копию, например в `my-pack`.
2. Откройте `mod.json` любым текстовым редактором (Блокнот, VS Code, Notepad++). Поменяйте `"id"` на то же имя, что у папки.
3. Удалите строку `"disabledByDefault": true`, иначе ваше дополнение тоже будет выключено по умолчанию.
4. Сохраните файл в кодировке **UTF-8**.
5. Запустите игру. Дополнение появится в разделе **Мастерская**; кнопка **«Изменить»** откроет его в редакторе.

Образец `example-pack` выключен по умолчанию: игра показывает его в списке, но не применяет, пока вы не поставите галочку и не перезапустите игру. В нём есть почти всё, о чём рассказано ниже: два сценария (один — на готовом мире), события по расписанию, свои названия и имена, свой зверь, правки баланса, седьмая эпоха и свои биомы.
{: .note}

### Минимальный mod.json

Вот рабочее дополнение с одним сценарием и одной целью:

```json
{
  "id": "my-pack",
  "name": { "ru": "Моё дополнение", "en": "My add-on" },
  "author": "Ваше имя",
  "description": { "ru": "Короткое описание для Мастерской", "en": "A short description for the Workshop" },
  "version": "1.0",
  "eraLadder": 3,
  "scenarios": [{
    "id": "first",
    "name": { "ru": "Первые века", "en": "The first centuries" },
    "desc": "Проведите людей через первые три века.",
    "boot": { "type": "continents", "seedPop": 40 },
    "goals": [
      { "text": { "ru": "Продержаться 300 лет", "en": "Survive 300 years" }, "metric": "year", "target": 300 }
    ]
  }]
}
```

Поля верхнего уровня:

| Поле | Что значит | Пример |
|---|---|---|
| `id` | служебное имя дополнения: латиница, цифры, дефис, до 40 знаков. Держите его таким же, как имя папки (редактор так и делает) | `"my-pack"` |
| `name` | название для игрока, до 60 знаков | `"Моё дополнение"` |
| `author` | автор, до 40 знаков | `"Ваше имя"` |
| `description` | описание, до 240 знаков (годится и имя `desc`) | `"Вулканы и холод"` |
| `version` | версия дополнения, до 16 знаков, — просто подпись | `"1.0"` |
| `eraLadder` | по какому счёту эпох написано дополнение (см. ниже). Новое дополнение — `3` | `3` |
| `disabledByDefault` | `true` — дополнение видно в списке, но не применяется, пока игрок сам его не включит | `true` |

**Зачем `eraLadder`.** До версии 2.1.2 эпох в игре было шесть, теперь восемь. Дополнение **без** `"eraLadder"` игра считает старым и переводит все номера эпох из старого счёта в новый (пороги, цели «эпоха N», здания по эпохам). С `"eraLadder": 2` номера эпох читаются по восьми эпохам. С `"eraLadder": 3` — то же, и цели «N открытий» считаются по полному списку из 65 открытий версии 2.2 (с `2` — по прежним 58). Редактор 2.2 ставит `3` сам. Пишете новое дополнение — ставьте `3`.
{: .note}

### Все разделы

Всё, кроме заголовка, необязательно. Берите только нужные разделы.

| Раздел | Что добавляет или меняет |
|---|---|
| `scenarios` | сценарии: стартовый мир, державы, цели, поражение |
| `worlds` | готовые миры (сохранения игры целиком) |
| `events` | события по расписанию в любой игре |
| `names`, `nameParts`, `cityNames`, `personNames` | названия держав, городов, имена людей и династий |
| `flags`, `flagShare` | флаги для держав, которые создаёт игра |
| `govNames` | свои названия форм правления и титулы |
| `species` | свои виды животных |
| `balance` | числа симуляции: рост, войны, климат, бедствия и сотни других |
| `eras` | своя лестница эпох |
| `vis` | цвета застройки и транспорта по эпохам |
| `biomes` | свои биомы |
| `models` | свои модели вместо встроенных форм зданий и транспорта |
| `buildings` | новые виды зданий |
| `vehicles` | свои машины на прогулке |
| `textures`, `roads` | текстуры игры и дорог |
| `sounds`, `music` | звуки событий и своя музыка |

Есть ещё раздел `code` — код, который меняет саму программу. Он описан в отдельной главе: [дополнения с кодом]({{ '/modding/code/' | relative_url }}).

### Текст на двух языках

Любой текст для игрока — название дополнения и сценария, описание, текст цели, запись хроники — можно задать одной строкой или парой:

```json
{ "name": { "ru": "Вулканическая зима", "en": "Volcanic Winter" } }
```

Игра покажет строку на языке игрока. Если одной половины нет, возьмёт другую. Игроки на остальных языках видят английскую строку (если её нет — русскую).

Из текста вырезаются `<`, `>`, `&`, обратная кавычка и обратная косая черта, а прямые кавычки и апостроф становятся типографскими. Разметку в текст вставить нельзя — это защита игрока.

### Служебные имена

У сценария, мира, вида животного, биома, здания и машины есть служебное имя (`id` или `key`). Игрок его не видит, а игра по нему узнаёт объект. Правила:

- только латиница, цифры и `_` (у `id` дополнения, мира и флага можно и дефис); остальное игра просто выбросит;
- в пределах одного дополнения имена не повторяются;
- **после публикации не меняйте** `id` сценария: по нему игра помнит, что сценарий пройден.

### Файлы и папки

Рядом с `mod.json` можно положить `preview.png` — витринную картинку для Мастерской. Остальные файлы удобно раскладывать по подпапкам:

```
my-pack/
  mod.json
  preview.png
  worlds/   готовые миры и их миниатюры
  tex/      картинки
  snd/      звуки
  music/    треки
  models/   модели .obj
```

Пути в `mod.json` пишутся **относительно папки дополнения** и только внутрь неё: `"tex/grass.png"`. Путь с `..`, абсолютный путь (`C:\…`) или ссылка на папку снаружи отбрасываются: у подписчиков такого файла всё равно бы не было.

### Если что-то не сработало

Игра **никогда не падает** из-за плохих данных дополнения: неверная запись пропускается с замечанием, всё остальное загружается.

- Откройте дополнение в редакторе: панель **«Проверка»** перечислит всё, что игра пропустит или исправит, и приведёт к нужному полю.
- Без редактора: запустите игру с ключом `--enable-logging=stderr` (Steam → свойства игры → параметры запуска) и найдите строки вида `[mods] my-pack: biomes[1].color: нужен цвет вида #rrggbb`.
- Ошибка в самом JSON (лишняя запятая, незакрытая скобка) не даёт прочитать файл целиком. Проверьте его любым проверщиком JSON или откройте в редакторе.

## Сценарии

Сценарий — это стартовый мир, условия старта и список целей. В одном дополнении — до 12 сценариев.

```json
{
  "scenarios": [{
    "id": "volcano",
    "name": { "ru": "Вулканическая зима", "en": "Volcanic Winter" },
    "desc": "Супервулкан затянул небо пеплом. Проведите людей через холод.",
    "boot": { "type": "continents", "solar": 0.94, "co2": 1.6, "disasterRate": 2, "seedPop": 40 },
    "lock": ["solar", "gtemp"],
    "lockTools": ["nuke", "rocket"],
    "enforce": { "solar": 0.94 },
    "states": [{ "name": "Кария", "x": 0.3, "y": 0.5, "tech": 4, "color": "#c0503a", "gov": "monarchy" }],
    "goals": [
      { "text": "Продержаться 200 лет", "metric": "year", "target": 200 },
      { "text": "Население 1,5 млн", "metric": "pop", "target": 1500000 },
      { "text": "Три державы классической эпохи", "metric": "statesAtEra", "param": 2, "target": 3 },
      { "text": "Удержать экологию выше 25%", "metric": "eco", "target": 0.25, "keep": true }
    ],
    "loseIfPopBelow": 2000,
    "loseAfterYear": 80,
    "lose": [{ "metric": "avgT", "below": -8, "text": "Ледник накрыл обитаемые земли." }],
    "events": [{ "year": 60, "do": "disaster", "type": "volcano", "at": "random", "power": 0.8 }]
  }]
}
```

Сценарий без единой правильной цели игра пропускает: его нельзя пройти.
{: .note .warn}

### Карточка сценария

| Поле | Что значит | Пример |
|---|---|---|
| `id` | служебное имя, до 32 знаков. По нему игра помнит пройденные сценарии | `"volcano"` |
| `name` | название, до 60 знаков | `"Вулканическая зима"` |
| `desc` | описание на карточке, до 300 знаков | `"Супервулкан…"` |
| `icon` | значок: один-два знака (буква, символ или эмодзи) | `"V"` |

### Стартовый мир — boot

| Поле | Значения | Что значит |
|---|---|---|
| `type` | `continents`, `earth`, `pangea`, `islands`, `empty`, `flat` | форма суши. `earth` — настоящая карта Земли, `empty` — сплошной океан (сушу лепит игрок). Без поля — `continents` |
| `w`, `h` | 24 … 400 | размер карты в клетках (без поля — 80×60) |
| `solar` | 0.7 … 1.4 | светимость Солнца, 1 — как у нас |
| `co2` | 0.2 … 6 | парниковый эффект, 1 — норма |
| `seaLevel` | 0.2 … 0.7 | уровень моря |
| `world` | путь к файлу | старт с [готового мира](#готовые-миры) из этого дополнения. Размер карты, год, державы и вся история берутся из файла; `type`, `w` и `h` не нужны |

Если файл мира из `world` не читается, сценарий пропускается: задуманный на готовом мире, на случайном он бессмыслен.

### Условия старта

Те же поля `boot`, что и в обычной «Новой игре»:

| Поле | Значения | Что значит |
|---|---|---|
| `pace` | 0.2 … 4 | темп истории: наука, рост, войны. 1 — обычный. Во время сценария игрок его не меняет |
| `disasterRate` | 0, 1, 2 | стихийные бедствия: выключены, обычно, часто (годится и имя `disasters`) |
| `dynSea` | `true` / `false` | «живое» море: уровень моря идёт вслед за климатом |
| `startYear` | −20000 … 20000 | год, с которого начинается летопись |
| `seedPop` | 0 … 2000 | сколько пригодных клеток получат первых жителей прямо на старте — игроку не придётся сеять людей самому |
| `eqShift` | −30 … 30 | сдвиг экватора, градусов к северу |
| `hist` | `true` / `false` | исторический старт на Реальной Земле (`"type": "earth"`): колыбели древних цивилизаций в 3000 г. до н. э. и волны новых народов. С готовым миром `world` не действует |
| `rules` | объект | правила мира — таблица ниже |
| `pins` | объект | закрепления: `"co2": 1` — игра держит CO₂ на месте, `"sea": 1` — уровень моря |

### Правила мира — rules

```json
{ "boot": { "type": "continents", "rules": { "noWar": 1, "collapse": 2, "maxStates": 12, "eraCap": 4 } } }
```

| Правило | Значения | Что значит |
|---|---|---|
| `noWar` | 0 или 1 | державы не воюют |
| `noRevolt` | 0 или 1 | без восстаний |
| `noAlliance` | 0 или 1 | без союзов |
| `lockBiomes` | 0 или 1 | биомы не меняются |
| `collapse` | 0, 1, 2 | распад держав: как в истории, редко, никогда |
| `startEra` | номер эпохи | с какой эпохи начинают новые державы (0 — с племён) |
| `maxStates` | 0 или 2 … 200 | не больше стольких держав (0 — без предела) |
| `era` | 0, 1, 2 + e | 0 — без ограничений; 1 — каждая держава остаётся в своей эпохе; 2 + e — потолок на эпохе e |
| `eraCap` | номер эпохи | то же, что `"era": 2 + e`, только понятнее: потолок на этой эпохе |
| `eraLock` | 1 | то же, что `"era": 1` |

Правила связывают только державы мира, не игрока: кисти и силы творца работают как обычно. Правило «не больше N держав» сильнее сценария: лишние стартовые державы не встанут.

### Стартовые державы — states

До 32 держав, которые будут на карте с первой секунды. Удобнее всего задавать их в редакторе (раздел «Державы»: карта сценария, кисть земли, столица, флаг), но руками тоже можно.

```json
{
  "states": [
    { "name": { "ru": "Кария", "en": "Caria" }, "x": 0.3, "y": 0.5, "capName": "Галикарн",
      "color": "#c0503a", "gov": "monarchy", "ideo": "", "era": 2, "pop": 60000,
      "stab": 0.8, "treasury": 5000, "gdpPc": 400,
      "traits": { "mil": 1.2, "tech": 1.1 },
      "culture": "карийцы", "religion": "Огонь",
      "area": { "w": 24, "h": 24, "rle": "250.4.20.4.20.4.20.4.250" },
      "flag": { "w": 6, "h": 4, "p": ["#2b2b2e", "#f08a1c"], "px": "AAAAAAAAAAAAAAAAAQEBAQEBAQEBAQEB" } },
    { "name": "Лидия", "x": 0.6, "y": 0.45, "color": "#3a7ac0", "gov": "republic" }
  ],
  "ties": [{ "a": 0, "b": 1, "k": "war" }],
  "statesMet": true,
  "allowPol": false
}
```

| Поле | Что значит |
|---|---|
| `x`, `y` | **обязательно**: столица в долях карты, 0 … 1 (0, 0 — левый верхний угол). Если точка в море или вне земли державы, столица встанет на ближайшую клетку её земли |
| `name` | имя (строка или пара), до 30 знаков. Без него — из генератора названий |
| `capName` | название столицы, до 30 знаков |
| `color` | цвет на карте, `#rrggbb` |
| `gov` | форма правления (список ниже). Держится 20 лет, как выбранная игроком |
| `ideo` | идеология: `feudal`, `capital`, `liberal`, `socialist`, `communist`, `fascist`, `democrat`, `centrist`; `""` — без идеологии. Держится 20 лет |
| `era` | эпоха (номер); наука поднимается до её порога. Эти знания — «до истории», а не первооткрытия |
| `tech` | стартовая наука, если удобнее задать числом (пороги эпох из коробки: 2, 5, 7, 9, 11, 13.5, 17) |
| `pop` | жителей, 1 000 … 20 000 000 (по умолчанию 20 000): гуще у столицы |
| `stab` | порядок, 0 … 1 |
| `treasury` | казна, 0 … 1 000 000 000 |
| `gdpPc` | богатство на жителя, 50 … 200 000 |
| `traits` | постоянные черты на всю жизнь державы: `mil` 0.5 … 1.5 (военная мощь), `gdp` 0.85 … 1.2 (хозяйство), `stab` −0.1 … 0.12 (добавка к порядку), `tech` 0.85 … 1.2 (наука). Можно указать только нужные |
| `culture`, `religion` | имя народа и веры, до 40 знаков. Одно имя у нескольких держав сценария — один народ, одна вера |
| `area` | нарисованная земля державы (см. ниже). Без неё держава получает клетки вокруг столицы |
| `flag` | пиксельный флаг (см. ниже). Это флаг игрока: его видно везде, где видны флаги |

**Формы правления** (`gov`): `tribe` племя, `chiefdom` вождество, `monarchy` королевство, `empire` империя, `theocracy` теократия, `republic` республика, `democracy` демократия, `dictatorship` диктатура, `technocracy` технократия, `federation` федерация, `duchy` герцогство, `emirate` эмират, `sultanate` султанат, `khanate` ханство, `caliphate` халифат, `constmon` конституционная монархия, `merchrep` торговая республика, `junta` военная хунта, `workers` рабочая республика.

#### Земля державы — area

`area` — маска `{ "w", "h", "rle" }` размером от 24 до 400 клеток по стороне. Клетки идут строками сверху вниз, в строке — слева направо. В `rle` через точку записаны длины серий «нет, да, нет, да…», **начиная с «нет»**. Сумма всех чисел должна быть равна `w × h`, длина строки — не больше 65 536 знаков.

В примере выше маска 24×24: 250 клеток «нет», потом 4 «да», 20 «нет», 4 «да» и так далее — квадрат 4×4 в середине. Маска другого размера, чем карта, пересчитывается на сетку мира, поэтому одна и та же маска годится для любого размера карты. Рисовать маски руками долго — используйте редактор: он запишет `area` сам.

#### Флаг державы — flag

`{ "w", "h", "p", "px" }`: размер от 4 до 64 клеток по стороне, `p` — палитра из 1 … 32 цветов `#rrggbb`, `px` — строка base64, в которой на каждую клетку один байт: номер краски в палитре. Клетки идут строками сверху вниз. В примере флаг 6×4: две верхние строки — краска 0, две нижние — краска 1.

#### Связи между державами — ties

Список `ties` лежит рядом со `states`, на уровне сценария:

| Поле | Что значит |
|---|---|
| `a`, `b` | номера двух держав в списке `states`, **с нуля** |
| `k` | вид связи: `ally` — союз, `vassal` — `a` вассал `b`, `war` — `a` объявляет войну `b`, `rel` — только отношения |
| `v` | отношения от −1 до 1 (у `rel` обязательно) |

Несовместимое (союз и война одной пары, два сюзерена, вассалитет по кругу) отбрасывается с замечанием. До 200 связей.

Ещё два поля сценария: `"statesMet": false` — державы сценария не знакомы друг с другом (по умолчанию, если держав две и больше, знакомы); `"allowPol": true` — игрок может менять строй, курс и дипломатию держав (иначе в сценарии это закрыто).

### Запреты — lock, lockTools, enforce

Без запретов многие цели проходятся одним движением ползунка.

**`lock`** — ползунки окна «Планета», недоступные игроку: `co2`, `solar`, `sea`, `gtemp` (глобальная температура), `tilt` (наклон оси), `dis` (частота бедствий), `dynsea` («живое» море). Можно указать и `pace`, но темп истории в сценариях заперт всегда.

**`lockTools`** — инструменты, недоступные игроку (до 48 в списке). Запрещённые кнопки приглушены, выбрать их нельзя. Осмотр запретить нельзя.

| Группа | Инструменты |
|---|---|
| Земля | `terrain`, `elevation`, `smooth`, `flatten` (выровнять), `water`, `river` (река), `resource`, `eraser`, `pin` (закрепить) |
| Климат | `temp`, `precip`, `wind`, `current` |
| Жизнь | `population`, `city`, `fauna` |
| Силы творца | `rain`, `bless`, `inspire`, `peace`, `discord` |
| Стихии | `volcano`, `quake`, `tsunami`, `hurricane`, `fire`, `meteor`, `plague`, `drought`, `flood`, `blizzard`, `asteroid`, `supervolcano`, `rift`, `zombie` |
| Оружие | `rocket`, `nuke` |
| Власть | `border`, `rebel`, `ally`; `polctl` закрывает все действия над державами на их странице (строй, курс, дипломатия); `landmark` — закладку достопримечательностей из окна города |
| Прогулка | `walk` |

**`enforce`** — значения, которые игра удерживает каждый тик, страховка от обходных путей:

| Поле | Что делает |
|---|---|
| `solar` | Солнце держится на этом значении (0.7 … 1.4) |
| `co2` | парниковый эффект не опускается ниже (0.2 … 6) |
| `disasters` | частота бедствий 0, 1 или 2 |

### Цели — goals

До шести целей. Каждая цель — показатель мира (`metric`), порог (`target`) и, у некоторых показателей, параметр (`param`):

```json
{ "text": "Три города-миллионника", "metric": "megacities", "param": 1000000, "target": 3 }
```

| Поле | Что значит |
|---|---|
| `text` | текст цели, до 120 знаков. Без него — «Цель N» |
| `metric` | показатель (таблицы ниже) |
| `target` | порог |
| `param` | параметр: у `statesAtEra` — номер эпохи, у `statesWithGov` — форма правления (как `gov` у держав), у `megacities` — число жителей |
| `below` | `true` — значение должно быть **не выше** порога (например, CO₂) |
| `keep` | `true` — цель нужно **удерживать** до конца. Без этого достигнутая цель засчитывается навсегда, даже если показатель потом упал |

Годы в целях считаются **от начала сценария**: на готовом мире 170-го года или со `startYear` цель «продержаться 200 лет» начинается с нуля.

### Поражение

Простые условия. Нет поля — нет условия.

| Поле | Проигрыш, когда |
|---|---|
| `loseIfPopBelow` | население упало ниже этого числа (засчитывается, только если люди на карте уже были) |
| `loseIfEcoBelow` | экология упала ниже порога (0 … 1) |
| `loseIfStatesBelow` | держав стало меньше N — но только после того, как их было не меньше N |
| `loseIfTempAbove`, `loseIfTempBelow` | средняя температура суши вышла за порог, °C |
| `loseIfExtinctAbove` | вымерло видов больше N |
| `loseAfterYear` | раньше этого года (от начала сценария) поражения не бывает. По умолчанию 60: в начале игры людей на карте ещё нет, и без отсрочки сценарий проигрывался бы сразу |

И свои условия — любой показатель выше или ниже порога, до шести штук:

```json
{
  "lose": [
    { "metric": "co2ppm", "above": 900, "text": "Парниковая катастрофа." },
    { "metric": "year", "above": 400, "text": "Время вышло." }
  ]
}
```

| Поле | Что значит |
|---|---|
| `metric`, `param` | показатель, как в целях |
| `above` или `below` | порог: проигрыш, когда значение выше `above` или ниже `below` (нужно хотя бы одно) |
| `text` | что увидит игрок, до 160 знаков |
| `after` | своя отсрочка в годах (без неё — `loseAfterYear`) |

### События сценария

Список `events` внутри сценария — те же [события по расписанию](#события-по-расписанию), только работают они в этом сценарии, а их годы считаются от его начала.

### Как сделать сценарий интересным

- **Ставьте цель или условие по времени.** Без него сценарий часто проходится за полминуты. На скорости ×20 одна секунда реального времени — примерно два игровых года: цель «300 лет» займёт около двух с половиной минут.
- **Не берите цели, которые выполняются сами.** «Пять держав» набирается за двадцать лет: держав на карте обычно под тридцать. Редактор показывает значение показателя в открытом сейчас мире — промотайте мир на нужное число лет и посмотрите, где окажется порог.
- **Осторожнее с экологией как целью на удержание.** За три века роста промышленности экология сама падает примерно до 20%. Для долгого сценария делайте экологию условием поражения (порог 10–15%), а не целью.
- **Готовый мир плюс ограничение по времени** — хороший рецепт: игрок начинает с живой историей, а условие `lose` по `year` не даёт тянуть бесконечно.

## Готовые миры

Мир — это сохранение игры целиком: рельеф, климат, державы, города, хроника и вся история. Дополнение может нести до восьми миров. Игрок видит их в главном меню и может начать игру в любом из них.

```json
{
  "worlds": [{
    "id": "ash-isles",
    "name": { "ru": "Пепельные острова", "en": "The Ash Isles" },
    "desc": "Архипелаг 60×40 клеток, 170-й год: одиннадцать держав.",
    "file": "worlds/ash-isles.json.gz",
    "thumb": "worlds/ash-isles.png"
  }]
}
```

| Поле | Что значит |
|---|---|
| `id` | служебное имя: латиница, цифры, `_` и `-`, до 32 знаков |
| `name`, `desc` | название (до 60 знаков) и описание (до 240) для игрока |
| `file` | файл мира — сохранение игры (**Сохранить → В файл**), можно сжатое gzip. До 64 МБ, карта от 24×24 до 400×400 |
| `thumb` | миниатюра png, jpg или webp до 1 МБ (необязательно) |

Сценарий начинает с такого мира полем `"boot": { "world": "worlds/ash-isles.json.gz" }`.

Проще всего добавить мир в редакторе: создайте мир в игре (сгенерируйте, вылепите кистями, заселите, промотайте историю), откройте дополнение и нажмите **Миры → Добавить текущий мир**. Редактор сам запишет файл и миниатюру в папку дополнения.

Мир из чужих рук игра не загружает как есть: из файла собирается **новое чистое сохранение**, в которое попадает только проверенное — поля мира нужного размера, числа в допустимых пределах, державы, города и хроника с очищенными строками. Сценарий, который шёл, когда мир сохраняли, к самому миру не относится и в файл не переносится.
{: .note}

## Мир из картинки

Карту высот (PNG или JPG) можно превратить в новый мир: светлое — горы, тёмное — море, прозрачное — тоже море. Климат, реки и биомы игра досчитает сама. Это делается только в редакторе: **Миры → Мир из картинки**.

- **Размер сетки** — от 24×24 до 400×400 клеток; кнопка «По пропорциям» подгоняет его под картинку.
- **Уровень моря на картинке** — какая яркость считается берегом.
- **Сглаживание** убирает одиночные пиксели-«иглы», из которых получились бы острова в одну клетку и горы-столбы.
- **Маска суши** (необязательно) — вторая картинка того же размера: белое — суша, чёрное — море. С маской берег определяет она, а карта высот задаёт только рельеф.

«Создать мир из картинки» перезапускает игру в новом мире. Дальше его можно доработать кистями, заселить и сохранить в дополнение кнопкой «Добавить текущий мир» — в `mod.json` он попадёт как обычный [готовый мир](#готовые-миры).

## События по расписанию

Раздел `events` на верхнем уровне `mod.json` — события, которые идут **в любой игре**, пока дополнение включено. Такой же список внутри сценария работает только в нём. До 32 событий в списке.

```json
{
  "events": [
    { "year": 150, "every": 250, "chance": 0.6, "do": "disaster", "type": "volcano", "at": "random", "power": 0.6,
      "text": { "ru": "Проснулся вулкан", "en": "A volcano has awakened" } },
    { "when": { "metric": "avgT", "below": 4 }, "every": 100, "do": "message", "kind": "disaster",
      "text": "Похолодание: средняя температура суши ниже 4 °C" },
    { "year": 300, "do": "climate", "solar": -0.03, "co2": 0.5, "text": "Небо потускнело" },
    { "when": { "metric": "warsTotal", "above": 10 }, "do": "power", "type": "peace", "at": "capital" }
  ]
}
```

### Когда

| Поле | Что значит |
|---|---|
| `year` | год события. В общем списке — год мира, в сценарии — от его начала |
| `when` | условие: `{ "metric": …, "above": … }` или `{ "metric": …, "below": … }`, показатель — как в целях (с `param`, если нужен) |
| `every` | повторять раз в столько лет; у события с условием — не чаще чем раз в столько лет |
| `chance` | вероятность 0 … 1 (по умолчанию 1) |
| `once` | `true` — сработать один раз, `false` — повторять |

Нужно хотя бы одно из `year` и `when`. Можно и то и другое: «при условии, но не раньше этого года».

Как повторяются события:

- Только `year` — один раз, в этот год.
- `year` и `every` — в этот год и потом каждые `every` лет.
- `when` — срабатывает, когда условие **становится** истинным. Без `every` и без `"once": false` — **только один раз**. С `every` или `"once": false` — снова, но лишь после того, как условие побывало ложным (и не чаще `every`).
- `chance` проверяется в момент срабатывания. Разовое событие по году, которому не повезло с вероятностью, второго шанса не получает.

Событие, чей год прошёл до того, как мир загрузили, считается состоявшимся. Что уже случилось, помнит сохранение.

### Что происходит — do

| `do` | Поля | Действие |
|---|---|---|
| `disaster` | `type`, `at`, `power` 0.1 … 1 (по умолчанию 0.6) | стихийное бедствие: `volcano`, `quake`, `tsunami`, `hurricane`, `fire`, `meteor`, `plague`, `drought`, `flood`, `blizzard` |
| `power` | `type`, `at`, `radius` 0.6 … 12 (по умолчанию 3), `power` 0.2 … 2 (по умолчанию 1) | сила творца: `rain` (дождь), `bless` (благо земли), `inspire` (озарение), `peace` (мир), `discord` (раздор) |
| `climate` | `solar`, `co2`, `seaLevel`, `absolute` | сдвиг климата: прибавки к Солнцу (±0.7), CO₂ (±5.8), уровню моря (±0.5). С `"absolute": true` — новые значения (Солнце 0.7 … 1.4, CO₂ 0.2 … 6, море 0.2 … 0.7) |
| `message` | `text` (обязателен) | только запись в хронику |

**Где — `at`:** `random` (случайное место; урагану и цунами — море, остальному — по возможности обжитая суша), `capital` (столица крупнейшей державы), `city` (крупнейший город), `land`, `ocean` или точка `[x, y]` в долях карты.

### Запись в хронике

| Поле | Что значит |
|---|---|
| `text` | текст записи, до 200 знаков |
| `kind` | вид записи (значок и цвет): `dawn`, `found`, `collapse`, `era`, `war`, `peace`, `alliance`, `secede`, `colony`, `famine`, `exodus`, `ruler`, `dynasty`, `revolt`, `reform`, `union`, `vassal`, `invention`, `wonder`, `religion`, `culture`, `disaster`, `plague`, `extinct`, `domestic`, `golden`, `capital`, `player`, `fauna`. У бедствия по умолчанию `disaster`, у остального — `dawn` |
| `imp` | заметность 0 … 3: 0 — тихо, только хроника; 2 — с уведомлением на экране (так по умолчанию у сообщений, у остального — 1); 3 — событие века |

## Названия, флаги, формы правления

### Державы, города, люди

```json
{
  "names": ["Вулкания", "Пепелград", "Обсидиан"],
  "nameParts": { "a": ["Пепел", "Магм"], "b": ["штадт", "поль"] },
  "cityNames": ["Кратер", "Серая Гавань"],
  "personNames": { "male": ["Игнат"], "female": ["Зола"], "dynasty": ["Пепловы"] }
}
```

- `names` — готовые названия держав. Игра раздаёт их первыми, а когда они кончаются — собирает новые из начал (`nameParts.a`) и окончаний (`nameParts.b`).
- `cityNames` — названия городов: новые города чаще получают их, остальные — из генератора.
- `personNames` — имена правителей и их родни (`male`, `female`) и правящих домов (`dynasty`).

До 400 названий в каждом списке, каждое до 30 знаков. Частей `nameParts` — до 200 в списке, каждая до 20 знаков.

### Флаги — flags

```json
{
  "flags": [
    { "id": "ash", "flag": { "w": 6, "h": 4, "p": ["#2b2b2e", "#f08a1c"], "px": "AAAAAAAAAAAAAAAAAQEBAQEBAQEBAQEB" } },
    { "id": "volcano", "names": ["Вулкан", "Vulcan"], "flag": { "w": 6, "h": 4, "p": ["#8c2b1c", "#f0c01c"], "px": "AAAAAAAAAAAAAAAAAQEBAQEBAQEBAQEB" } },
    { "id": "arc", "cultures": ["аркад"], "flag": { "w": 6, "h": 4, "p": ["#1c4a8c", "#ffffff"], "px": "AAAAAAAAAAAAAAAAAQEBAQEBAQEBAQEB" } }
  ],
  "flagShare": 0.5
}
```

Это флаги для держав, которые создаёт сама игра: племён, отколовшихся провинций, колоний. Рисунок `flag` — тот же, что у [стартовых держав](#флаг-державы--flag).

| Поле | Что значит |
|---|---|
| `id` | служебное имя флага |
| `flag` | рисунок |
| `names` | части имени державы (до 16): флаг достаётся державам, в чьём названии есть одна из них. Давайте части на обоих языках — в английской игре имена держав латиницей |
| `cultures` | части имени народа (до 16): флаг достаётся державам этого народа (например, народа, названного в сценарии) |

Флаги без `names` и `cultures` — общий набор. Его получает доля `flagShare` (0 … 1, по умолчанию 1) остальных держав. Выбор зависит только от державы и её имени, поэтому один и тот же при каждом показе. Флаг, нарисованный игроком, всегда сильнее. До 200 флагов. В редакторе флаг можно нарисовать в пиксельном редакторе игры или сделать из картинки.

### Названия форм правления — govNames

```json
{
  "govNames": {
    "monarchy": { "ru": "Огненное царство", "en": "Fire Kingdom", "de": "Feuerreich",
                  "state": { "ru": "Царство", "en": "Tsardom" },
                  "lead": { "ru": "Царь-кузнец", "en": "Smith King" } }
  }
}
```

Ключ — форма правления игры (список — в разделе [Стартовые державы](#стартовые-державы--states)). Внутри:

- `ru`, `en` и коды других языков (`de`, `fr`, `zh-CN`…) — название формы, до 30 знаков;
- `state` — слово в имени державы, если оно иное, чем название формы (у конституционной монархии — «Королевство X»);
- `lead` — титул главы.

Задавать все три не обязательно — меняется только то, что указано. Новое название видно везде: в имени державы, окнах, хронике, газетах, речи жителей. Языку без своего названия достаётся английское. Титулы правителей в родословных остаются игровыми.

## Свои животные

```json
{
  "species": [{
    "key": "ashfox", "ru": "Пепельная лисица", "en": "Ash fox",
    "guild": "pred", "model": "wolf",
    "temp": [-15, 18], "precip": [150, 1200],
    "size": 0.6, "herd": [1, 3], "speed": 1.2, "danger": 0.1
  }]
}
```

| Поле | Что значит |
|---|---|
| `key` | служебное имя: латиница, цифры, `_`, до 24 знаков. Не должно совпадать со встроенным видом |
| `ru`, `en` | название, до 40 знаков |
| `guild` | **обязательно**, кто это: `herb` (травоядное), `pred` (хищник), `fish` (морская жизнь), `bird` (птица) |
| `model` | облик из встроенных форм: `deer`, `boar`, `bison`, `horse`, `camel`, `elephant`, `mammoth`, `rabbit`, `goat`, `wolf`, `bear`, `lion`, `tiger`, `penguin`, `seal`, `whale`, `fish`, `shark`, `bird`, `eagle`. Без поля — олень, волк, рыба или птица по `guild` |
| `temp`, `precip` | климат, в котором живёт вид: температура, °C, и осадки, мм в год. По ним игра подбирает виду биомы |
| `size`, `speed` | размер и скорость, 0.1 … 10 (1 — обычные) |
| `herd` | размер стада `[от, до]`, 1 … 500 |
| `danger` | опасность, 0 … 1 (у хищника по умолчанию 0.5) |
| `domestic` | `true` — травоядное можно одомашнить |
| `biomes` | вместо подбора по климату — веса по биомам суши 0 … 1: `{ "tundra": 1, "borealForest": 0.5 }` |
| `sea` | для морских видов: три веса 0 … 1 — глубины, шельф, риф (по умолчанию `[0.6, 1, 0.6]`) |
| `dens` | плотность: особей на км² в лучших местах (по умолчанию 3, у хищника 0.1) |
| `r` | скорость прироста, 0.01 … 2 (по умолчанию 0.3) |
| `vuln` | уязвимость к охоте и людям, 0.05 … 20 (по умолчанию 1; у кролика 0.15, у бизона 1.3) |

Ключи встроенных биомов для `biomes`: `tundra` тундра, `borealForest` тайга, `coldDesert` холодная пустыня, `temperateGrassland` степь, `temperateDeciduous` широколиственный лес, `temperateRainforest` дождевой лес умеренной зоны, `mediterranean` средиземноморье, `subtropicalDesert` пустыня, `savanna` саванна, `tropSeasonalForest` сезонный тропический лес, `tropRainforest` тропический дождевой лес, `alpine` альпийские луга, `barrenRock` скалы, `scorched` выжженная пустошь, `marsh` болото, `mangrove` мангры, `iceSheet` ледник (а также водные `deepOcean`, `oceanShelf`, `coral`). Годятся и ключи своих биомов дополнения.

До 16 видов. В уже идущем мире новый вид сам не появляется — его подселяют кистью «Животные»; новому миру он достаётся при создании.

## Баланс

Раздел `balance` меняет числа, по которым живёт мир: скорость роста населения, частоту войн, чувствительность климата к CO₂ и сотни других.

```json
{
  "balance": {
    "civ":       { "R_BASE": 0.05, "WAR_P": 0.03, "TECH_RATE": 0.008 },
    "climate":   { "T_equator": 32, "co2Sens": 4.5 },
    "ecology":   { "GROW": 0.03 },
    "currents":  { "windGain": 1.2 },
    "society":   { "REVOLT": 0.06 },
    "disasters": { "P_VOLCANO": 0.02 },
    "music":     { "GAP": [5, 15] }
  }
}
```

Что значат параметры из примера (в скобках — значение из коробки):

| Параметр | Что меняет |
|---|---|
| `civ.R_BASE` (0.042) | базовый прирост населения |
| `civ.WAR_P` (0.05) | склонность держав к войнам |
| `civ.TECH_RATE` (0.006) | скорость технологий |
| `civ.TEMPO` (0.34) | общий темп истории: наука, рост, войны |
| `civ.TECH_ERA_K` (8 чисел) | скорость науки по эпохам — массив, по числу на эпоху |
| `climate.T_equator` (30) | температура на экваторе, °C |
| `climate.co2Sens` (3.6) | на сколько градусов теплеет мир при удвоении CO₂ |
| `music.GAP` ([10, 25]) | тишина между треками встроенной музыки, секунд от и до |

### Разделы

| Раздел | Что внутри |
|---|---|
| `civ` | люди, хозяйство, державы, войны, пороги эпох (`AT_*`), знакомство держав (`CONTACT_*`) |
| `climate` | климат, морской лёд, ядерная зима |
| `ecology` | рост растительности, плодородие, загрязнение |
| `currents` | океанские течения |
| `society` | культуры, веры, восстания, реформы |
| `disasters` | стихийные бедствия и кратеры (`CR_*`) |
| `fauna` | животный мир |
| `people` | правители и династии |
| `walk` | прогулка от первого лица |
| `stats` | статистика и летопись |
| `sound`, `music` | звук и встроенная музыка: громкости, паузы, переходы |
| `trade` | товары, партии груза, торговые пути |
| `corp` | компании, акции и модели заводов |
| `history` | исторический старт на Реальной Земле |
| `politics` | формы правления, идеологии, набожность |
| `diplomacy` | провинции, блоки, мировой совет, договоры, мировые войны |
| `army` | полки, фронт, снабжение, командиры |
| `airwar` | война в воздухе |
| `nuclear` | ядерное оружие |
| `landmarks` | достопримечательности |
| `ruins` | руины и их ветшание |
| `epidemic` | эпидемии и мертвецы |
| `city3d` | облик городов на 3D-карте |
| `terrain` | кисть «Выровнять» |

### Правила

- Менять можно **только уже существующие** параметры. Новый ключ игра не примет, а редактор и консоль скажут «нет такого параметра».
- Число заменяется числом, массив — массивом чисел **той же длины**.
- Значения обрезаются до ±1 000 000. Разумные пределы каждого параметра показывает редактор (ползунок), но не навязывает: за ними мир может вести себя странно.
- Несколько служебных параметров менять нельзя (например, `ruins.Y_OFS`, `city3d.TPL_SALT`, `corp.BRAND_SKIP`): игра скажет об этом в проверке.

**Где взять список всех параметров.** Откройте дополнение в редакторе, раздел **«Баланс»**: там каждый параметр всех разделов с подписью, значением из коробки (отмечено чёрточкой на ползунке), подсказкой при наведении, поиском и фильтром «только изменённые». Подробнее — в главе про [редактор дополнений]({{ '/modding/editor/' | relative_url }}).
{: .note}

Правки разделов `walk`, `stats`, `sound`, `music`, `city3d` и `terrain` историю мира не меняют: такой мир по-прежнему считается в таблицах лидеров Steam. Правки остальных разделов меняют историю — мир с ними в таблицы лидеров не попадает.

## Свои эпохи

Из коробки эпох восемь:

| Номер | Эпоха | Порог науки |
|---|---|---|
| 0 | Племена | — |
| 1 | Аграрная | 2 |
| 2 | Классическая | 5 |
| 3 | Средневековая | 7 |
| 4 | Индустриальная | 9 |
| 5 | Постиндустриальная | 11 |
| 6 | Современная | 13.5 |
| 7 | Космическая | 17 |

Раздел `eras` переписывает лестницу целиком:

```json
{
  "eraLadder": 3,
  "eras": {
    "tech":  [2, 5, 9, 13, 17, 21],
    "names": {
      "ru": ["Племена", "Аграрная", "Классическая", "Индустриальная", "Современная", "Космическая", "Звёздная"],
      "en": ["Tribal", "Agrarian", "Classical", "Industrial", "Modern", "Space Age", "Interstellar"]
    },
    "agri":       [0.3, 1.2, 2.6, 6, 11, 18, 26],
    "military":   [0.5, 1, 1.6, 2.5, 3.6, 5, 7],
    "seafaring":  [0, 1, 1, 2, 3, 4, 5],
    "transition": [0, 0.15, 0.45, 0.8, 0.9, 0.96, 0.98],
    "techSpeed":  [3.4, 2.2, 1.55, 1.3, 1.15, 1, 0.9],
    "cityCap":    [0.07, 0.15, 0.3, 0.55, 1, 1, 1],
    "look":       [0, 1, 2, 3, 4, 5, 5]
  }
}
```

**Главное правило длины.** `tech` — пороги *входа* в эпохи, их N штук (от 1 до 11). Эпоха 0 порога не имеет, поэтому эпох получается **N + 1** (не больше 12), и все остальные массивы обязаны быть длиной N + 1. В примере: 6 порогов — 7 эпох — массивы по 7 чисел.
{: .note .warn}

| Массив | Что значит |
|---|---|
| `tech` | сколько науки нужно, чтобы войти в эпоху. Числа должны возрастать |
| `names.ru` | названия эпох, до 24 знаков (обязательно). `names.en` необязателен — без него берётся русский |
| `agri` | множитель сельского хозяйства |
| `military` | множитель военной силы |
| `seafaring` | дальность мореходства |
| `transition` | демографический переход, 0 … 1: насколько снижен прирост населения. 0 — рожают как в племенах, 0.96 — как в современном городе |
| `techSpeed` | необязательно: скорость науки в эпохе (ранние эпохи идут быстрее) |
| `cityCap` | необязательно: потолок размера города в эпохе — доля от потолка населения клетки |
| `look` | необязательно: на какую из шести «видимых» эпох похожа каждая ваша (0 племена, 1 аграрная, 2 классическая, 3 индустриальная, 4 современная, 5 космическая). По ней игра выбирает облик застройки, транспорт прогулки и музыку. Без таблицы видимые эпохи раскладываются по вашим пропорционально |

Если эпох стало больше или меньше, проверьте пороги в `balance.civ` (`AT_MISSILE` и прочие `AT_*`): они заданы номерами эпох и останутся там, где стояли.

**Как вставить эпоху между существующими.** Пороги `tech` должны расти, поэтому новую эпоху вписывайте в середину всех массивов сразу, в одну и ту же позицию. В редакторе проще: добавьте эпоху кнопкой «Добавить» (она встанет последней), впишите ей порог и нажмите «Расставить по порядку» — эпоха переедет на своё место вместе с названием и всеми множителями.

## Вид эпох

Раздел `vis` перекрашивает застройку и транспорт 3D-карты по эпохам:

```json
{
  "vis": {
    "3": { "house": "#c9b79a", "factory": "#b8a68c", "land": "#8c3b2e" },
    "4": { "tower": "#e8f4ff", "plane": "#f0f8ff" }
  }
}
```

Ключ — номер **видимой** эпохи. Их шесть: 0 — племена, 1 — аграрная, 2 — классическая и средневековая, 3 — индустриальная и постиндустриальная, 4 — современная, 5 — космическая. Так же нумеруются эпохи в разделах `models` и `roads`. Если дополнение задаёт свою лестницу (`eras`), ключ — номер её эпохи.

Внутри — цвета `#rrggbb`:

| Ключ | Что красит |
|---|---|
| `tent` | шалаш |
| `house` | дом |
| `factory` | завод |
| `tower`, `towerAlt` | небоскрёб и его второй тип |
| `landmark` | памятник |
| `land`, `landAcc` | наземный транспорт и его прицеп или деталь |
| `ship`, `sail` | корабль и парус |
| `plane` | самолёт |
| `rail`, `wagon` | локомотив и вагоны |

Указывать все не нужно: что не задано, остаётся прежним. Эпоху, которой нет в таблице, можно дописать — она начнётся как копия последней.

## Свои биомы

Встроенные биомы определяются деревом правил внутри игры. Свои описываются **климатическим конвертом** и проверяются **раньше** встроенных.

```json
{
  "biomes": [{
    "key": "volcanic",
    "ru": "Вулканическая пустошь",
    "en": "Volcanic waste",
    "color": "#4a3f3a",
    "colorLush": "#5c5048",
    "arable": 0.05,
    "rough": 0.9,
    "priority": 10,
    "texture": "tex/waste.png",
    "veg": { "sprite": "tex/dead_tree.png", "d": 3, "height": 0.6, "width": 0.9 },
    "when": { "temp": [24, 60], "precip": [0, 500], "height": [0.3, 1], "water": false }
  }]
}
```

| Поле | Что значит |
|---|---|
| `key` | служебное имя: латиница, цифры, `_`. Не должно совпадать с другим биомом |
| `ru`, `en` | название, до 40 знаков |
| `color` | **обязательно**: основной цвет `#rrggbb` |
| `colorLush` | цвет при густой растительности (без него — `color`) |
| `arable` | пригодность к земледелию, 0 … 1 (по умолчанию 0.2): сколько людей прокормит клетка |
| `rough` | зернистость текстуры на 2D-карте, 0 … 1 |
| `priority` | −100 … 100: чем больше, тем раньше проверяется правило |
| `texture` | своя бесшовная текстура рельефа в 3D (png, jpg, webp) |
| `veg.mesh` | встроенная растительность: `conifer`, `broadleaf`, `jungle`, `bush`, `field` |
| `veg.sprite` | **или** свой спрайт — png с прозрачностью; `height` и `width` — размеры (0.1 … 3) |
| `veg.d` | плотность растений, 0 … 8 |

### Условия when

| Поле | Диапазон | Что значит |
|---|---|---|
| `temp` | −90 … 90 | температура, °C |
| `precip` | 0 … 6000 | осадки, мм в год |
| `height` | 0 … 1 | высота над уровнем моря |
| `slope` | 0 … 2 | крутизна склона |
| `water` | `true` / `false` | только вода или только суша |
| `coast` | `true` / `false` | только у берега или только вдали от него |

Любое поле можно опустить — тогда оно не проверяется. Все указанные условия должны выполняться одновременно. До 24 своих биомов.

Слишком узкий конверт — и биом не появится ни разу; слишком широкий — и он вытеснит половину карты. Начните со средних значений и посмотрите в игре.
{: .note}

## Модели, виды зданий, транспорт

### Требования к модели

Формат — **Wavefront OBJ** (`.obj`). Он экспортируется из Blender, 3ds Max, SketchUp, Cinema 4D и почти всего остального.

- **Масштаб не важен:** модель вписывается в единичный куб и ставится на землю, дальше её размером управляет игра.
- **Ориентация:** ось Y — вверх, модель смотрит вдоль +X.
- **Для текстуры нужна UV-развёртка** (строки `vt` в файле). Без неё текстура ляжет одним пикселем.
- Материалы (`.mtl`) игнорируются: текстура берётся из `mod.json`.
- Четырёхугольники и многоугольники разбиваются на треугольники сами.
- До 12 МБ на модель, до 8 МБ на её текстуру (png, jpg, webp).

Экспорт из Blender: File → Export → Wavefront (.obj), включите «Triangulated Mesh» и «UV Coordinates», «Materials» можно выключить.

### Свои модели — models

Раздел `models` **подменяет** встроенную форму:

```json
{
  "models": {
    "house":   { "obj": "models/house.obj", "texture": "models/house.png" },
    "factory": "models/factory.obj",
    "tower":   { "4": { "obj": "models/sky.obj", "texture": "models/sky.png" } },
    "mover_land": { "0": "models/cart.obj", "4": ["models/car.obj", "models/van.obj"] },
    "mover_sea": "models/ship.obj",
    "mover_air": "models/plane.obj"
  }
}
```

Четыре способа записи:

- `"house": "models/house.obj"` — одна модель на все эпохи; **красит игра** цветом эпохи и державы, как встроенные формы.
- `"house": { "obj": "…", "texture": "…" }` — модель **со своей текстурой**: показывается как нарисовал автор, цвет эпохи на неё не ложится.
- `"tower": { "4": … }` — своя модель на конкретную видимую эпоху (номера — как в [виде эпох](#вид-эпох)).
- `"mover_land": { "4": ["…", "…"] }` — **несколько моделей** транспорта (на все эпохи или на одну, до 64): каждая машина 3D-карты берёт одну из них. Списком можно задавать только транспорт `mover_…`.

| Форма | Что это |
|---|---|
| `tent`, `house`, `factory`, `tower`, `landmark` | шалаш, дом, завод, небоскрёб, памятник |
| `mover_land` | наземный транспорт 3D-карты |
| `mover_sea` | суда |
| `mover_air` | самолёты |
| `mover_war` | военный корабль морских сражений |
| `mover_rail` | локомотив (вагоны остаются встроенными) |

### Новые виды зданий — buildings

Раздел `models` подменяет встроенную форму, а `buildings` **добавляет новый вид**: здание занимает часть построек и ставится на те же улицы, что и обычные дома.

```json
{
  "buildings": [{
    "key": "temple",
    "model": { "obj": "models/temple.obj", "texture": "models/temple.png" },
    "replaces": "house",
    "where": "city",
    "eras": [2, 5],
    "chance": 0.2,
    "size": 1.6,
    "color": "#d8c39c"
  }]
}
```

| Поле | Что значит |
|---|---|
| `key` | служебное имя: латиница, цифры, `_`, до 24 знаков |
| `model` | путь к `.obj` или `{ "obj": …, "texture": … }` — как в `models` |
| `replaces` | чьё место занимает: `house`, `tent`, `factory`, `tower`, `landmark` (без поля — `house`) |
| `where` | `any` — везде, `city` — только города, `center` — сёла-центры, `village` — хутора |
| `eras` | `[с какой, по какую]` настоящую эпоху (номера по восьми эпохам) |
| `chance` | доля построек, 0.01 … 1 (по умолчанию 0.15). 0.2 — примерно каждая пятая |
| `size` | множитель размера, 0.2 … 4 |
| `color` | цвет, если у модели нет своей текстуры |

Выбор зависит от координат: одно и то же здание всегда стоит на одном месте и не мерцает между кадрами. До 12 своих видов.

### Свой транспорт — vehicles

Раздел `vehicles` **добавляет свои машины**. Каждая — облик одного из встроенных видов транспорта прогулки: своя машина ездит, стоит и воюет там же, где этот вид, с его скоростью, местами и прочностью — у части машин этого вида в своих эпохах. Своих машин у одного вида может быть сколько угодно: хоть пятьдесят легковых на эпоху.

```json
{
  "vehicles": [{
    "key": "zil130",
    "name": { "ru": "ЗИЛ-130", "en": "ZIL-130" },
    "model": { "obj": "models/zil130.obj", "texture": "models/zil130.png" },
    "replaces": "truck",
    "eras": [6, 6],
    "chance": 0.3,
    "size": 1,
    "color": "#4a6a3a"
  }]
}
```

| Поле | Что значит |
|---|---|
| `key` | служебное имя: латиница, цифры, `_`, до 24 знаков. Одно на все включённые дополнения: по нему машину узнают и другие игроки сетевой комнаты |
| `name` | имя в подсказках прогулки, до 40 знаков; без него — имя встроенного вида |
| `model` | путь к `.obj` или `{ "obj": …, "texture": … }` |
| `replaces` | **обязательно**: облик какого вида — таблица ниже |
| `eras` | `[с какой, по какую]` настоящую эпоху (номера по восьми эпохам) |
| `chance` | доля машин этого вида, 0.01 … 1 (по умолчанию 0.25). Доли своих машин одного вида складываются; в сумме 1 и больше — встроенного облика у этого вида в эти эпохи не остаётся |
| `size` | множитель длины, 0.3 … 3 (1 — длина встроенного вида) |
| `color` | цвет, если у модели нет своей текстуры; без него — обычная окраска вида |

| Где ездит | Виды (`replaces`) |
|---|---|
| Улицы и дороги | `oldcar` самоходный экипаж, `lorry` первый грузовик, `car30` легковая 1930–40-х, `lorry30` грузовик 1930–40-х, `bus30` капотный автобус, `taxi30` такси 1930-х, `van30` фургон 1930-х, `roadster` родстер, `car` седан, `hatch` хэтчбек, `suv` внедорожник, `van` фургон, `pickup` пикап, `taxi` такси, `minibus` маршрутное такси, `truck` грузовик, `semi` седельный тягач, `bus` автобус, `hover` аэромобиль, `hbus` аэробус, `htruck` грузовой аэромобиль, `htaxi` аэротакси |
| Полиция | `police30` полицейская машина 1930-х, `police` патрульная машина, `hpolice` патрульный аэромобиль |
| Пожарные и скорые | `ftruck30` пожарная машина 1930-х, `ftruck` пожарная машина, `hftruck` пожарный аэромобиль, `amb30` санитарная машина 1930-х, `amb` скорая помощь, `hamb` санитарный аэромобиль |
| Вода у берега | `canoe` долблёнка, `boat` лодка, `sailboat` парусная яхта, `launch` паровой катер, `mboat` катер, `yacht` моторная яхта, `hboat` аэроглиссер |
| Армия: базы и сражения | `acar` бронеавтомобиль, `rtank` ромбовидный танк, `tank` средний танк, `htrack` полугусеничный БТР, `apc` бронетранспортёр, `mbt` основной боевой танк, `htank` парящий танк |

- Какая машина какой модели, решает её зерно: одна и та же машина всегда одной модели — и у всех игроков сетевой комнаты.
- Длину модели игра подгоняет под встроенный вид. Из-за руля виден салон встроенного вида: у модели `.obj` салона нет.
- Машины видов «Улицы и дороги» ездят и по дорогам 3D-карты: своя машина берёт там свою долю потока своей эпохи.
- Повозки, кареты, колесницы, конные пожарные и санитарные упряжки и верховых животных модель пока не заменяет: модель неподвижна, а кони и волы шагают. Своих жителей тоже нельзя: люди на прогулке двигаются по суставам.
- До 400 своих машин в одном дополнении, их модели вместе — до 160 МБ (они разбираются при запуске игры).

## Текстуры, дороги, звуки, музыка

### Текстуры игры

```json
{ "textures": { "grass": "tex/grass.png", "water": "tex/water.png" } }
```

Имена: `grass`, `sand`, `snow`, `rock`, `cobble`, `planks`, `water`, `wall_stone`, `wall_timber`, `wall_glass`, `wall_concrete`, `tree_broadleaf`, `tree_conifer`, `tree_jungle`, `bush`, `field`.

Форматы png, jpg, webp, до 8 МБ на файл. Текстуры рельефа должны быть **бесшовными**: они повторяются плиткой.

### Дороги по эпохам

```json
{ "roads": { "2": "tex/road_stone.png", "4": "tex/road_asphalt.png" } }
```

Ключ — номер видимой эпохи (как в [виде эпох](#вид-эпох)). Текстура ложится **вдоль** дороги, поэтому должна быть бесшовной по вертикали. Где текстуры нет, остаётся стандартный цвет эпохи.

### Звуки

```json
{ "sounds": { "war": "snd/war.wav", "thunder": "snd/thunder.ogg", "step": "snd/step.wav" } }
```

Дополнение может заменить любой звук игры:

| Группа | Имена |
|---|---|
| Хроника и интерфейс | `click` (клик), `paint` (кисть), `ach` (достижение), `win` (победа), `lose` (поражение), `era` (новая эпоха), `war` (война), `city` (основан город), `collapse` (распад державы), `famine` (голод), `colony` (колония), `disaster`, `peace`, `ruler`, `invention`, `extinct`, `plague`, `revolt` |
| Мир и прогулка | `rain`, `thunder`, `quake`, `eruption`, `splash`, `engine`, `horn`, `hover`, `animal`, `step`, `gallop`, `oar`, `door`, `talk`, `coin`, `take`, `battle`, `alarm`, `cannon`, `explosion`, `crash`, `thud`, `sword`, `swing`, `clash`, `arrow`, `shot`, `reload`, `empty`, `draw`, `hit`, `hurt`, `shout`, `scream` |

Полный список видит редактор (раздел «Файлы» → «Звуки событий»): он берёт его у самой игры. Форматы ogg, wav, mp3, до 4 МБ на файл — это короткие звуки, а не музыка.

### Музыка

```json
{ "music": ["music/theme.mp3", "music/calm.ogg"] }
```

Музыка дополнения **заменяет встроенный саундтрек целиком**: пока она играет, встроенный композитор молчит. Треки идут по кругу, громкость подчиняется ползунку музыки в настройках. До 12 треков, до 24 МБ каждый. Форматы: mp3, ogg, wav, m4a, flac.

Тонкие настройки звука и встроенной музыки (громкости, паузы между треками, переходы) меняются через `balance.sound` и `balance.music`.

## Проверка, удаление, публикация

### Проверка

1. Откройте дополнение в редакторе: панель **«Проверка»** покажет всё, что игра пропустит или исправит, с адресом до поля.
2. **«Проверить в игре»** сохраняет дополнение, включает его и сразу запускает выбранный сценарий (или новый мир, если сценариев нет).
3. Без редактора: сохраните `mod.json` и перезапустите игру или нажмите **«Обновить»** в Мастерской. Сценарии появятся в списке **Сценарии** вместе со встроенными, миры — в главном меню.
4. Если что-то не подхватилось, запустите игру с `--enable-logging=stderr` и прочитайте строки `[mods]`.

### Как удалить дополнение

- **Своё** (лежит в `mods`): кнопка **«Удалить»** в разделе Мастерская. Папка стирается с диска, поэтому игра спрашивает подтверждение. Изменения вступят в силу после перезапуска.
- **Подписка Мастерской**: кнопкой в игре не удаляется. Отпишитесь на странице предмета (кнопка **«Страница в Мастерской»** ведёт прямо туда) — Steam сам уберёт файлы. Если стереть их вручную, Steam просто скачает их обратно.
- **Уже опубликованный предмет**: удаление локальной папки его не трогает. Предмет удаляется на своей странице в Мастерской, в меню владельца.

Создание дополнения **никуда его не отправляет** — папка просто лежит в `mods`. В Мастерскую попадает только то, что вы явно отправили кнопкой «Опубликовать», и там ещё спрашивается подтверждение.

### Публикация в Мастерскую

Публикуют из редактора, раздел **«Публикация»**:

- **Картинка для витрины** — `preview.png`: «Снять с текущей карты» (2D или 3D, что сейчас на экране за меню) или «Выбрать картинку»; редактор приводит её к 640×360.
- **Перед отправкой** — короткий список: нет ли ошибок, есть ли описание и картинка.
- **Что изменилось** — заметка для подписчиков, уходит вместе с обновлением.
- **Опубликовать** — предмет создаётся **скрытым** в вашем аккаунте. Чтобы его увидели другие, зайдите на страницу предмета в Мастерской, примите соглашение и переключите видимость.

Требования к папке: обязателен `mod.json`, желателен `preview.png`. Все файлы должны лежать **внутри** папки дополнения. В Мастерскую уезжает вся папка, поэтому лишние файлы (обзор в редакторе их показывает) лучше убрать.

**Повторная публикация обновляет тот же предмет.** Номер предмета игра запоминает в файле `workshop.id` рядом с `mod.json` — не удаляйте его и не меняйте руками. Видимость предмета при обновлении не трогается. Чтобы выложить дополнение отдельным новым предметом, нажмите в редакторе «Отвязать» (или удалите `workshop.id`) перед отправкой. «Дублировать дополнение» делает копию без `workshop.id`.
{: .note}

Если публикация не удалась, игра пишет причину словами. Отдельный случай — когда предмет создался, а файлы не залились: причину Steam пишет только в свой журнал `logs\workshop_log.txt` в папке Steam.

## Ограничения и лимиты

Данные дополнения **декларативны**: игра читает их и сама решает, что с ними делать, но ничего из них не выполняет. Это защита игрока — файлы приезжают от посторонних людей через интернет. Поэтому:

- цели и события описываются показателем, порогом и действием из готового списка, а не формулой;
- менять можно только те параметры, которые в игре уже есть;
- числа обрезаются до допустимых пределов, массивы обязаны сохранять длину;
- из строк вырезается разметка;
- файлы читаются **только изнутри папки дополнения**;
- на каждый вид файла есть предел размера;
- мир из файла пересобирается заново, а не загружается как есть.

Неверные записи не ломают дополнение целиком: игра пропускает их, пишет замечание и загружает всё остальное. Всё, что сверх лимита, отбрасывается с замечанием.

| Стартовых держав в сценарии | 32 |

| Запрещённых инструментов | 48 |

| Готовых миров | 8 |
