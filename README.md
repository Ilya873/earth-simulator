# Earth Simulator — звёздная карта развития и полевой дневник

Сайт игры [Earth Simulator](https://store.steampowered.com/app/4932460/Earth_Simulator/): интерактивная дорожная карта
в виде звёздной карты, летопись версий и дневник разработки.

**Адрес:** https://ilya873.github.io/earth-simulator/ (английская версия — `/en/`)

Сайт собирает GitHub Pages (Jekyll) сам: достаточно закоммитить изменения в ветку `main`, и через минуту они на сайте.

## Как опубликовать запись в дневнике

1. Создайте файл `_posts/ГГГГ-ММ-ДД-латинское-название.md`, например `_posts/2026-11-20-vyshlo-obnovlenie-2-1.md`.
2. Картинки и короткие ролики положите в папку `assets/devlog/ГГГГ-ММ-ДД-название/`.
3. Шапка и текст записи:

```markdown
---
title: "Вышло обновление 2.1"
title_en: "Update 2.1 is out"            # необязательно — заголовок для английской версии
summary: "Порты, поезда, самолёты и военные базы."
summary_en: "Ports, trains, planes and military bases."
version: "2.1.0"                         # необязательно
cover: /assets/devlog/2026-11-20-update/cover.jpg   # обложка — она же картинка превью в Telegram
cover_caption: "Подпись к обложке"
body_en: |                               # необязательно — английский текст, появится переключатель языка
  English text in Markdown.
---
Текст записи в Markdown.

{% include figure.html src="/assets/devlog/2026-11-20-update/port.jpg" caption="Морской порт" %}
{% include gallery.html images="/assets/devlog/2026-11-20-update/a.jpg|/assets/devlog/2026-11-20-update/b.jpg" captions="Первый|Второй" %}
{% include video.html youtube="ID_ролика" caption="Трейлер обновления" %}
```

Видео: `youtube="…"`, `rutube="…"`, `vk="полная ссылка video_ext.php"` или свой файл `src="/assets/devlog/…/clip.mp4"` (до ~20 МБ).

## Как обновить дорожную карту

Всё в `_data/roadmap.yml`. Каждое обновление — звёздная система, каждый пункт — планета на её орбите:

- статус пункта — `s: done | wip | plan | idea` (в игре / в работе / запланировано / задумка). Готовые планеты светятся;
- статус обновления — `status:`; метка «Вы здесь» — `now: true` (ровно у одного);
- идея игроков — `req: true` (подсвечивается фильтром «Идеи игроков»);
- примерный срок — `when:` (с «≈»), положение на шкале времени — `t:` (доля года), место на карте — `pos:`.

## Летопись версий и Telegram

- Новая версия — блок сверху в `_data/versions.yml` (список изменений, ссылка на новость в Steam и пост в Telegram).
- Посты канала издателя на сайте — номера в `_data/telegram.yml` (последняя часть ссылки `t.me/gamesforfarmnews/3755`).

## Устройство

| Путь | Что там |
|---|---|
| `_layouts/` | каркас страниц: главная, дневник, запись |
| `_includes/home/` | разделы главной: титульная карта, «Мир сегодня», звёздная карта, летопись версий, дневник |
| `_data/` | дорожная карта, версии, посты Telegram, подписи к скриншотам, строки интерфейса RU/EN |
| `assets/css/main.css` | всё оформление (цвета — переменные в начале файла) |
| `assets/js/atlas.js` | живая физическая карта на титульном листе |
| `assets/js/starmap.js` | звёздная карта развития |
| `assets/js/site.js` | увеличение картинок, виджет Steam, язык записей |
| `en/` | английская версия главной и дневника |
